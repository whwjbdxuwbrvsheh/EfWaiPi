### Simple Phishing Detection System

A basic phishing detection system developed as part of our Final Year Project (FYP) proposal. The system aims to analyse suspicious URLs and assess their **phishing sophistication level** and **phishing probability** to help users identify potential phishing threats.

**Key Objectives:**
- Analyse URL characteristics and suspicious patterns.
- Evaluate phishing sophistication based on identified indicators.
- Estimate the probability of a URL being associated with phishing.
- Present detection results to help users assess potential threats.
